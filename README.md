# 60-30-10

**60-30-10** est un outil web bilingue FR/EN d’Eigrutel Lab consacré à la répartition d’une palette selon la règle **60 % / 30 % / 10 %**.

Il permet d’explorer rapidement trois rôles colorés — dominante, secondaire et accent — soit librement, soit à partir de caractères colorés prédéfinis. L’outil affiche également plusieurs formats colorimétriques pour chaque couleur.

**Version stable : 1.0.0 — 12 août 2026**

## Fonctionnalités

- répartition visuelle 60 / 30 / 10 ;
- mode **Classique / Classic** avec réglages OKLCH indépendants ;
- mode **Caractère / Character** avec profils Vivid, Muted, Dark et Pale ;
- décalage global de teinte en mode Caractère ;
- génération de nouvelles dispositions par clic ou toucher ;
- affichage HEX, RGB, HSL, HSV, CMJN/CMYK, Lab et OKLCH ;
- copie rapide des valeurs couleur ;
- interface bilingue français / anglais ;
- mémorisation locale des réglages dans le navigateur ;
- fonctionnement autonome, sans compte ni serveur.

## Utilisation

Ouvrir `603010.html` dans un navigateur moderne ou utiliser la page GitHub Pages du dépôt.

Le fichier `index.html` sert de page de présentation et donne accès à l’application.

## Données et confidentialité

60-30-10 fonctionne localement dans le navigateur. Les préférences sont enregistrées via `localStorage`. Aucune donnée n’est envoyée à un serveur par l’application elle-même.
